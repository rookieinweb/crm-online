# CRM Online

> 基于 **uni-app + Vue 3** 开发的轻量级在线客户关系管理（CRM）应用。

当前项目已实现个人电子名片展示功能，可作为 CRM 系统的移动端基础模块，后续可进一步扩展客户管理、销售管理、联系人管理等业务能力。

## ✨ 项目介绍

CRM Online 是一个面向移动端的在线客户关系管理项目。

项目基于 uni-app 开发，支持编译为微信小程序及 H5 等多端应用。目前已完成个人电子名片页面，包括个人信息展示、名片分享以及一键拨打电话等基础功能。

项目整体采用 Vue 3 技术体系，并集成 Pinia 状态管理，为后续 CRM 功能扩展提供基础架构支持。

## 💻 开发环境

建议使用以下环境进行开发：

* Node.js >= 18
* npm >= 9
* HBuilderX（推荐）
* 微信开发者工具（微信小程序开发）

## 📦 安装依赖

克隆项目：

```bash
git clone https://github.com/rookieinweb/crm-online.git
```

进入项目目录：

```bash
cd crm-online
```

安装依赖：

```bash
npm install
```

## ▶️ 运行项目

### 运行到 H5

```bash
npm run dev:h5
```

### 运行到微信小程序

```bash
npm run dev:mp-weixin
```

## 📦 项目构建

### 构建 H5

```bash
npm run build:h5
```

### 构建微信小程序

```bash
npm run build:mp-weixin
```

构建完成后，可在 `dist` 目录中查看对应平台的编译产物。

### 名片功能

用户可以通过页面进行：

* 查看个人信息
* 分享个人名片
* 一键拨打联系电话

其中拨打电话功能使用 uni-app 提供的：

```javascript
uni.makePhoneCall()
```

实现移动端原生拨号能力。
